개인정보처리방침 (Privacy Policy)

www.code0.ai.kr 개인정보처리방침

시행일: 2026년 10월 31일

Code0(정영신, 이하 “운영자”)는 개인 포트폴리오 사이트 www.code0.ai.kr(이하 “사이트”)를 운영하며, 방문자의 개인정보를 소중히 여깁니다. 이 방침은 사이트 이용 과정에서 어떤 정보가 처리되는지 설명합니다.

1. 운영자가 직접 수집하는 개인정보

사이트에는 회원가입, 로그인, 댓글, 문의 양식 등 개인정보를 입력받는 기능이 없습니다. 운영자는 방문자의 개인정보를 직접 수집하거나 저장하지 않습니다.

방문자가 이메일로 직접 연락하는 경우, 운영자는 회신을 위해 해당 이메일 주소와 내용만 이용하며 다른 목적으로 사용하거나 제3자에게 제공하지 않습니다.

2. 호스팅 및 서버 로그

사이트는 GitHub Pages(GitHub, Inc.)에서 호스팅됩니다. 방문자가 사이트에 접속하면 GitHub가 보안 및 서비스 운영을 위해 IP 주소 등 접속 정보를 기록할 수 있습니다. 운영자는 이 로그에 접근하지 않습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.

3. 외부 리소스

사이트는 페이지 표시를 위해 다음 외부 서비스에서 리소스를 불러옵니다. 이 과정에서 각 서비스 제공자에게 방문자의 IP 주소와 브라우저 정보가 전달될 수 있습니다.

  • jsDelivr, cdnjs (Cloudflare): 스타일시트 및 JavaScript 라이브러리 제공
  • Google Fonts: 웹 글꼴 제공
  • github-readme-stats, github-profile-trophy (Vercel): repositories 페이지의 GitHub 통계 이미지 제공

사이트에는 방문자 분석 도구(Google Analytics 등)와 댓글 서비스가 설정되어 있지 않습니다.

4. 쿠키 및 브라우저 저장소

운영자는 추적 목적의 쿠키를 사용하지 않습니다. 사이트는 방문자가 선택한 화면 테마(라이트/다크 모드)를 기억하기 위해 브라우저의 로컬 저장소(localStorage)에 설정값을 저장하며, 이 값은 운영자에게 전송되지 않습니다.

5. Google AdSense 등 제3자 광고

사이트에는 Google AdSense를 통한 광고가 게재될 수 있습니다. 광고가 게재되는 경우:

  • Google을 포함한 제3자 공급업체는 쿠키를 사용하여 방문자의 이 사이트 또는 다른 웹사이트 방문 기록을 기반으로 광고를 게재할 수 있습니다.
  • Google은 광고 쿠키를 사용하여 방문자에게 이 사이트 및 인터넷의 다른 사이트 방문 기록에 기반한 광고를 게재할 수 있습니다.
  • 방문자는 Google 광고 설정에서 맞춤 광고를 사용 중지할 수 있습니다.
  • Google이 파트너 사이트에서 정보를 사용하는 방식은 Google 파트너 사이트 정책에서 확인할 수 있습니다.

6. 방침 변경

이 방침이 변경되면 이 페이지에 변경 내용과 시행일을 게시합니다.
